This document describes the OSC, MIDI, and native/binary protocols for remotely controlling the Behringer WING mixing console. It also describes the C-language `wapi` API along with program/source code examples, for developers to build console-control applications. Reference and user-guide chapters cover console capabilities and operation, such as effect, GPIO use, and routing.
